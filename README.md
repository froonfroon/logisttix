> **نظام لوجستي سحابي متطور وشامل لإدارة عمليات الشحن، المستودعات الذكية (WMS)، أسطول التوزيع، بوابات التجار (B2B)، والتسويات المالية الفورية.**

---

## 🌟 أبرز مميزات النظام (Key Features)

### 1. 🏢 بوابة الإدارة والعمليات المركزية (Enterprise Admin Portal)
- **لوحة قيادة تنفيذية (Executive Dashboard):** مؤشرات أداء فورية (KPIs)، نسبة التسليم الناجح (Success Rate)، معدل المرتجعات، وإجمالي تحصيلات الدفع عند الاستلام (COD).
- **إدارة الطلبات والشحنات (Order Lifecycle):** دورة معالجة كاملة تبدأ من التأكيد وحتى التسليم، مع إمكانية طباعة بوالص الشحن (Waybills) وباركود AWB الفوري.
- **إدارة المستودعات (WMS & Inbound Hub):** فحص واردات التجار، إدارة أذونات الاستلام، وجرد وتخصيص المخازن والأرفف.
- **إدارة المناديب والأسطول (Fleet & Drivers):** كشوف تسليم وتوزيع جغرافية، مراقبة الكاش والتحصيلات، وإقفال يومي للمناديب.
- **التسويات والمالية (Finance & Cash Close):** سحب مستحقات التجار، إصدار فواتير ضريبية، وتقارير دورية لأرباح العمليات.
- **اعتماد وتدقيق التجار (Merchant KYB Approvals):** نظام تدقيق شامل للطلبات الجديدة مع إمكانية الموافقة، تحديد الخصومات ونقاط الاستلام، أو الاعتذار مع توضيح الأسباب.
- **إدارة الصلاحيات المتقدمة (RBAC):** دعم لأدوار قيادية متعددة (مدير عام، مدير تشغيل، مشرف مستودعات، رئيس حسابات).

### 2. 🛍️ بوابة التجار والشركاء (Merchant Self-Service Portal)
- **لوحة بيانات المتجر:** إحصائيات المبيعات، الشحنات النشطة، الأرباح المستحقة، ورصيد المحفظة المتاح للسحب.
- **إنشاء وتتبع الطلبات:** إضافة شحنات فردية أو استيراد جماعي عبر Excel/CSV، وإصدار بوالص الشحن بنقرة واحدة.
- **إدارة المخزون والتوريد (Inbound Requests):** جدولة إرسال بضائع للمستودع المركزي لمتابعة الجرد وطلبات التجهيز.
- **إدارة المرتجعات وفحص الجودة (QC & Returns):** تصنيف المرتجعات (سليم، تالف، مفقود) مع توثيق الأسباب.
- **المحفظة والفواتير:** طلب تحويل بنكي لمبالغ COD، تحميل فواتير الشحن، وتتبع التسويات اليومية.
- **الربط البرمجي (Webhooks & API Tokens):** مفاتيح ربط مخصصة لمنصات المتاجر (Zid, Salla, Shopify, WooCommerce).
- **إعدادات المتجر وفريق العمل:** إضافة موظفين وتحديد صلاحياتهم (مالك، مدير، محاسب، موظف تجهيز).

### 3. ✨ بوابة الدخول الموحدة والتسجيل (Auth & Onboarding Gateway)
- **دخول موحد فخم (Dark Glassmorphism UI):** واجهة قيادية تدعم التبديل السريع بين حسابات الإدارة المعتمدة، حسابات المتاجر، والتتبع السريع.
- **تسجيل تجار جديد بنظام KYB (3-Step Wizard):**
  1. هوية المتجر والنشاط التجاري.
  2. بيانات المسؤول ومواقع استلام البضائع (Pickup Address).
  3. التوثيق البنكي والآيبان (IBAN) للتحويلات التلقائية.
- **شاشة المتابعة الحية لطلب الاعتماد (`MerchantPendingScreen`):** متتبع حي من 4 مراحل لحالة الطلب مع زر اتصال واتساب مباشر للدعم.

### 4. 📦 تتبع الشحنات العام (Public Live Tracking)
- تتبع آني لمسار الشحنة برقم البوليصة أو الهاتف دون الحاجة لتسجيل دخول، متوافق كلياً مع الهواتف الذكية.

## 🔒 الأمان والموثوقية (Security & Clean Architecture)

- **Zero Hardcoded Secrets:** لا توجد أي مفاتيح سرية أو بيانات اعتماد مخزنة داخل الكود المصدري.
- **Clean Type-Safe Codebase:** تطبيق كامل لمعايير TypeScript الصارمة مع 0 أخطاء برمجية (`tsc -b` Clean).
- **Enterprise RBAC:** عزل كامل لصلاحيات المستأجرين (Multi-Tenant Isolation) بحيث يرى كل تاجر بياناته الخاصة فقط.
- **Audit Logs:** سجل تدقيق أمني لكافة العمليات الحساسة (إنشاء شحنة، تسوية مالية، تغيير أسعار، وتعديل صلاحيات).

## 🛠️ حزمة التقنيات المستخدمة (Tech Stack)

- **Frontend Core:** React 19, TypeScript 5.9, Vite 8.3
- **Styling & UI:** Tailwind CSS, Lucide Icons, Glassmorphic Design System
- **State Management:** React Context Architecture (Auth, Data, Theme, Toast)
- **Typography:** Cairo & Inter Font Families

## 🚀 التشغيل والتثبيت محلياً (Getting Started)

### المتطلبات الأساسية:
- Node.js (الإصدار 18 فما فوق)
- npm أو pnpm أو yarn

### خطوات التشغيل:
```bash
# 1. تثبيت الحزم والمكتبات
npm install

# 2. بدء سيرفر التطوير المحلي
npm run dev

# 3. بناء النسخة الإنتاجية
npm run build
```
